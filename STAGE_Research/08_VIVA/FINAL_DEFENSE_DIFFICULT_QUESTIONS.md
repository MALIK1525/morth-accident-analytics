# Difficult Defense Questions (25)

Covers ML null, weather causality, exposure, vintages, novelty, K-means, overspeeding, safety counts, app validity. Each entry: question, why asked, best answer, one-liner, what not to say.

1. ML lost, why pass? / Tests honesty. / Aggregate features insufficient; null is evidence. / "The null is the finding." / Never "model works".
2. Weather just correlation? / Causality probe. / Yes, labeled so with FDR and caveats. / "Association only." / Never mechanism.
3. Overspeeding responsible? / Causal trap. / Reported share, not proven cause. / "Records, not mechanisms." / Never "caused".
4. Better model? / Method challenge. / Data-bound, five families tested. / "Features, not algorithms." / Never promise wins.
5. Deep learning? / Hype check. / Would overfit N=213. / "GBR already overfit." / Never agree blindly.
6. Trust govt data? / Source challenge. / Verified via reconciliation, not trusted. / "Zero mismatches." / Never blind trust.
7. Excluded records? / Cherry-pick suspicion. / 18 nulls documented, never zeroed. / "Documented exclusion." / Never hide.
8. Why multi-level? / Scope check. / India, zone, state answer different questions. / "Levels plus layers." / Never vague.
9. What is new? / Novelty probe. / Package contribution, bounded claims. / "Framework plus honesty." / Never breakthrough.
10. Different dataset, different numbers? / Robustness. / Vintages differ; separation handles it. / "Separation, not merging." / Never deny.
11. Why not merge MoRTH+NCRB? / Integration push. / Definitions incompatible. / "Parallel only." / Never merge.
12. Why not 2014-2024? / Continuity push. / Boundary breaks. / "Breaks stay visible." / Never smooth.
13. Predict tomorrow? / Overclaim bait. / No; yearly state counts only, and loses to baseline. / "Firm no." / Never hedge.
14. Most dangerous road? / Granularity bait. / No road-level data. / "Firm no." / Never guess.
15. Dangerous states from clusters? / Label bait. / No exposure, no risk labels. / "Firm no." / Never rank.
16. Weather mechanism? / Causal bait. / None proposed. / "No mechanism claimed." / Never invent.
17. Rain reduces accidents? / Sign misread. / Tendency with confounders, not effect. / "No causal reading." / Never prescribe.
18. 2020 dip meaning? / Anomaly probe. / Observed dip plus recovery, contextualized. / "Described, not explained causally." / Never assert cause.
19. Counts versus risk? / Core understanding. / Big is not dangerous without denominator. / "Denominator logic." / Never conflate.
20. Association vs causation? / Philosophy check. / Moving together versus changing outcomes. / "Design decides." / Never blur.
21. Ladakh gaps? / Missing-data probe. / UT did not exist; history flagged. / "Boundary history." / Never impute.
22. Severity rising why? / Explanation push. / Components reported, no single cause asserted. / "Pattern, not cause." / Never speculate.
23. Pure scale effect? / Confounder push. / Plausibly partial; disclosed with sensitivity. / "Conceded, documented." / Never dismiss.
24. Dashboard misuse? / Responsibility. / Guardrail text on every surface. / "Counts are not risk." / Never shrug.
25. One line to pass? / Closer. / Verified, reproducible, honestly limited evidence base. / "Evidence plus integrity." / Never oversell.
